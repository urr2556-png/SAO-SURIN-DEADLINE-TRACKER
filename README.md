# ⏰ SAO-SURIN-DEADLINE-TRACKER

## Smart Document and Task Deadline Tracking System

### ระบบติดตามหนังสือราชการและงานที่ครบกำหนด
**สำนักตรวจเงินแผ่นดินจังหวัดสุรินทร์**  
State Audit Office of the Kingdom of Thailand – Surin

---

## 1. ความเป็นมาและความสำคัญ (Background)

ระบบ SAO-SURIN-DEADLINE-TRACKER เป็นนวัตกรรมด้านการบริหารจัดการและติดตามหนังสือราชการ งานที่ได้รับมอบหมาย และภารกิจที่มีกำหนดระยะเวลาดำเนินการของสำนักตรวจเงินแผ่นดินจังหวัดสุรินทร์ โดยประยุกต์ใช้เทคโนโลยีดิจิทัลในการติดตามสถานะ เฝ้าระวังความเสี่ยง และแจ้งเตือนกำหนดระยะเวลาดำเนินงาน

ระบบได้รับการออกแบบให้ผู้บริหารและเจ้าหน้าที่สามารถตรวจสอบสถานะการดำเนินงานผ่าน Dashboard เพื่อป้องกันความล่าช้า ลดความเสี่ยงต่อความเสียหาย และเพิ่มประสิทธิภาพในการบริหารจัดการภารกิจของหน่วยงาน

## 2. วัตถุประสงค์ (Objectives)

- ติดตามหนังสือราชการและงานที่ได้รับมอบหมายอย่างเป็นระบบ
- แจ้งเตือนงานที่ใกล้ครบกำหนด ครบกำหนด และเกินกำหนด
- ลดความเสี่ยงจากการดำเนินงานล่าช้า
- สนับสนุนการกำกับดูแลและการตัดสินใจของผู้บริหาร
- เพิ่มประสิทธิภาพ ความโปร่งใส และความรับผิดชอบในการปฏิบัติงาน
- สนับสนุนนโยบายการเปลี่ยนผ่านสู่การทำงานดิจิทัล (Digital Transformation)

## 3. ข้อมูลที่จัดเก็บ (Data Management)

| ลำดับ | รายการข้อมูล | Data Field |
|---|---|---|
| 1 | ชื่อเรื่อง/ชื่องาน | Task Title |
| 2 | วันที่เริ่มดำเนินการ | Start Date |
| 3 | วันที่ครบกำหนด | Due Date |
| 4 | เวลาครบกำหนด | Due Time |
| 5 | ผู้รับผิดชอบ | Responsible Officer |
| 6 | หน่วยงานที่ต้องแจ้ง | Notification Agency |
| 7 | ระดับการแจ้งเตือน | Alert Level |
| 8 | ชื่อผู้บันทึกข้อมูล | Recorded By |
| 9 | สถานะการดำเนินงาน | Task Status |

## 4. ระบบแจ้งเตือนอัจฉริยะ (Smart Alert System)

ระบบจำแนกระดับการแจ้งเตือนออกเป็น 4 ระดับ โดยประมวลผลจากวันและเวลาที่ครบกำหนด

| ระดับ | สี | สถานะ | การแสดงผล |
|---|---|---|---|
| Level 1 | 🟢 เขียว | ปกติ (Normal) | แสดงผลปกติ |
| Level 2 | 🟡 เหลือง | ใกล้ครบกำหนด (Warning) | กระพริบช้า |
| Level 3 | 🟠 ส้ม | ถึงวันครบกำหนด (Due Today) | กระพริบเร็ว |
| Level 4 | 🔴 แดง | เกินกำหนด (Overdue) | กระพริบเร็วมาก |

ระบบแสดงระดับความเร่งด่วนตามวันและเวลาปัจจุบัน เพื่อให้ผู้รับผิดชอบสามารถจัดลำดับการดำเนินงานได้อย่างเหมาะสม

## 5. Executive Dashboard

ระบบแสดงข้อมูลสรุปสำหรับผู้บริหาร ประกอบด้วย

- จำนวนงานทั้งหมด (Total Tasks)
- จำนวนงานสถานะปกติ (Normal Tasks)
- จำนวนงานใกล้ครบกำหนด (Warning Tasks)
- จำนวนงานถึงวันครบกำหนด (Due Today Tasks)
- จำนวนงานเกินกำหนด (Overdue Tasks)
- จำนวนและสัดส่วนร้อยละของแต่ละระดับ
- กราฟวงแหวนแสดงสถานะการแจ้งเตือน (Donut Chart)
- ตารางรายละเอียดงานและผู้รับผิดชอบ
- นาฬิกาแสดงวันและเวลาปัจจุบัน

## 6. ระบบจัดอันดับความเสี่ยง (Risk Ranking System)

ระบบจัดลำดับงานและผู้รับผิดชอบตามระดับความเร่งด่วน เพื่อสนับสนุนการเฝ้าระวังความเสี่ยงจากการดำเนินงานล่าช้า

ลำดับการแสดงผลจากความเร่งด่วนสูงสุดไปต่ำสุด

1. 🔴 งานเกินกำหนด
2. 🟠 งานถึงวันครบกำหนด
3. 🟡 งานใกล้ครบกำหนด
4. 🟢 งานสถานะปกติ

การจัดอันดับดังกล่าวเป็นเครื่องมือสนับสนุนการบริหารงาน ไม่ใช่การประเมินความผิดหรือผลการปฏิบัติงานของบุคลากรโดยตรง

## 11. การรักษาความมั่นคงปลอดภัยของข้อมูล (Data Security)

ระบบมุ่งเน้นการรักษาความมั่นคงปลอดภัย ความถูกต้อง และความครบถ้วนของข้อมูลราชการ ตามหลักการดังนี้

- Confidentiality — การรักษาความลับของข้อมูล
- Integrity — การรักษาความถูกต้องครบถ้วนของข้อมูล
- Availability — ความพร้อมใช้งานของข้อมูล
- Accountability — ความรับผิดชอบและการตรวจสอบย้อนหลัง

ระบบต้นแบบจัดเก็บข้อมูลภายในเว็บเบราว์เซอร์ ยังไม่มีฐานข้อมูลกลางและระบบควบคุมสิทธิ์ผู้ใช้งาน จึงไม่ควรนำข้อมูลลับหรือข้อมูลราชการที่มีความอ่อนไหวมาใช้งานจนกว่าจะมีมาตรการรักษาความปลอดภัยที่เหมาะสม
